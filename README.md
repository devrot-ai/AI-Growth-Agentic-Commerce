# AI Growth Agentic Commerce

Machine-readable commerce API definitions and validation examples.

## Contents

- `spec/`: Versioned JSON Schema and OpenAPI definitions
- `examples/`: Example payloads for each specification version
- `scripts/`: Consistency validation tooling

## Setup

Install dependencies with pnpm:

```sh
pnpm install
```

Run the consistency checks:

```sh
pnpm validate:all
```

The retained `LICENSE` and `NOTICE` files apply to the specification material in this repository.
